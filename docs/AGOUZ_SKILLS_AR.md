# مهارات Codex في Agouz

المهارات موجودة في `.agents/skills`. يحدد `skills-lock.json` المصدر والمرجع المثبت. شغّل `npx skills list --agent codex` من جذر المشروع لعرضها. لمراجعة تحديث، نزّل نسخة المصدر المطابقة لمرجع Git في مكان منفصل أولًا، وافحص الفرق والسكربتات باستخدام `skill-scanner`. يسترجع Git الإصدار المعتمد عند الرجوع إلى إصدار سابق من المشروع.

| المهارة | التطبيق في Agouz |
|---|---|
| Modern Web Guidance | مراجعة دعم المتصفح للحقول والنوافذ قبل التعديل |
| frontend-design | ترتيب إدخال البيانات ومراجعتها بالهوية البيضاء والبنية والذهبية |
| web-design-guidelines | مراجعة أسماء الحقول والتركيز واللمس ورسائل الخطأ |
| playwright | اختبار النسخة المحلية بحسابات وملفات اصطناعية، وتصوير الشاشات عند الحاجة |
| security-best-practices | مراجعة دفاعية لمسارات الدخول وExcel وPDF مع مهارات Supabase |
| gh-fix-ci | تشخيص الاختبار الفاشل من سجلات GitHub Actions |
| skill-scanner | فحص مهارات الطرف الثالث قبل تفعيلها |
| sentry | قراءة أخطاء التطبيق المصنفة حسب الإصدار بعد ربط الخدمة |

## تشغيل التحقق

- شغّل `npm run check` ثم `npm test` و`npm run build`. اختبار PostgreSQL المدمج يعمل بخادم مؤقت داخل سير العمل Verify Agouz. اختبارات Python لها سير عمل مستقل.
- سير العمل Agouz focused visual review يختبر الواجهة على أكثر من عرض شاشة ودورة رفع التقارير والفاتورة بملفات اصطناعية. سير العمل Agouz slow mobile performance يقيس عرضًا بعرض 360 بكسل مع شبكة بطيئة و10,000 فاتورة اختبار.
- عند تعطل فحص، شغّل `python .agents/skills/gh-fix-ci/scripts/inspect_pr_checks.py --repo . --pr رقم-طلب-الدمج`. فشل معاينة Vercel يظهر في سجل النشر على Vercel.
- مثال فحص مهارة بعد مراجعة المصدر هو `uv run --no-project --with PyYAML==6.0.3 .agents/skills/skill-scanner/scripts/scan_skill.py .agents/skills/playwright`. النتائج الآلية تحتاج مراجعة بشرية. أمثلة قواعد الفحص تسببت في تحذيرات عند فحص الأداة لنفسها. تعذر نسخ أحد ملفات الأمثلة في Windows، واستُخدم السكربت وقواعده المضمنة بنجاح.

## المراقبة الاختيارية

مهارة Sentry مثبتة. المشروع يحتاج مؤسسة ومشروعًا في Sentry لتفعيل الإرسال. اضبط `VITE_SENTRY_DSN` في نسخة المعاينة أولًا، وحدد مرجع الإصدار عبر `VITE_AGOUZ_RELEASE` عند البناء المحلي. يستمد بناء Vercel مرجع الإصدار من Git. وصول CLI يحتاج تسجيل دخول على حساب مخول بالقراءة.

عند التفعيل، ترسل الواجهة فئة ثابتة لكل من أخطاء عرض الشاشة أو ملفات النسخة القديمة، ومعها الإصدار والبيئة ووقت الحدث ومعرّفه. تُستبعد تفاصيل الخطأ وبيانات الطلبات والمستخدمين والفواتير. اترك المتغير فارغًا لإيقاف الإرسال. اختبر حدثًا اصطناعيًا في المعاينة قبل تفعيل الإرسال في الإنتاج.

## مراجعة دفاعية

تحقق مسار الاستيراد من الجلسة ومطابقة ملكية المهمة، ويعامل ملف Excel كبيانات غير موثوقة ويطبق حدود التحليل. اختبار قاعدة البيانات يثبت فصل حساب الكاشير عن قراءات المتجر، ورفض التكرار والتحقق من قيمة Begun. تصدير PDF يمر بطلب مصرح به مع ترويسات تمنع تخزين الرد الخاص. اختبارات المتصفح تستخدم خادمًا محليًا مع بيانات اصطناعية، واختبارات الخادم تختبر القيود والحسابات في بيئة منفصلة.

تجربة التقريرين الأصليين على جهاز الكاشير خطوة قبول ميداني حين يتوفر الجهاز.
